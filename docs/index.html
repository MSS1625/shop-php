راه‌اندازی نسخه کامل

۱ دریافت و نصب وابستگی‌ها

پروژه را کلون کنید و وابستگی‌ها را با Composer نصب کنید.

git clone https://github.com/MSS1625/shop-php.git cd shop-php composer install
۲ نصب یک‌مرحله‌ای

فایل env، کلید، مهاجرت‌ها، داده نمونه و لینک تصاویر — همه با یک فرمان.

php artisan shop:install
۳ مدیر و اجرا

کاربر مدیر را تعاملی بسازید و سرور داخلی را بالا بیاورید.

php artisan admin:create php artisan serve # http://localhost:8000
terminal — راه‌اندازی کامل در ۴ فرمان
$ git clone https://github.com/MSS1625/shop-php.git && cd shop-php $ composer install $ php artisan shop:install && php artisan admin:create $ php artisan serve → http://localhost:8000 🎉
